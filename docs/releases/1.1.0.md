# Waydroid Manager 1.1.0

## New features

- Enable a second Android screen for individual app shortcuts or only the Waydroid shortcut. The plugin requests and returns the host's secondary output alongside other Armada applications.
- Link a companion app to open on the second screen while focus stays on the primary app.
- Use arbitrary whole-number Steam frame caps on compatible Android 13 images, with live updates and each screen limited to its own native refresh rate.
- Access **Host > Home** and mounted external drives automatically through Android's file picker. Contents remain writable; the Host, Home and drive entries are protected from deletion, renaming and moving.
- Scale Android's interface with the Steam launch resolution and generate higher-resolution Steam artwork from the actual launcher icon.

## Improvements and fixes

- First-enable progress prepares image-specific second-screen resources locally with tools included in the plugin. No compiler packages or dependency downloads are required on the device.
- Launch-scoped overlays preserve installed images and existing overlay policies. A separate guard handles cleanup if the backend disappears.
- Super Hexagon starts at the saved 120 FPS target without toggling Steam's limiter. Live changes to 14 FPS and back to 120 were verified on Nova.
- Installation approval remains tied to the selected install when Android focus changes, and background startup waits for the Android user to unlock.
- Second-screen options follow host capabilities, and **Uninstall Waydroid** is inside **Waydroid actions**.

## Compatibility and upgrade

Install `waydroid-manager-1.1.0.zip` through Decky's ZIP installer after closing running Android shortcuts. Existing Android apps, data and plugin preferences are retained. Resource caches are validated again after image or recipe changes.

The shipped native profile supports Android 13 / VNDK 33 / ARM64 after interface validation. Thor and Nova were used for hardware checks; other images and devices require their own validation. Second-screen support also requires a secondary host Wayland output. Ordinary Waydroid launches retain their installed configuration.

Independent Android shortcuts still share one Steam window identity. Use companion links for two apps that should belong to the same Steam launch. Some first-launch permission dialogs still require opening the Waydroid shortcut and granting permission there before retrying the app shortcut.

CI passed 310 Python tests, 13 frontend tests, native mount isolation and package checks before release preparation.
